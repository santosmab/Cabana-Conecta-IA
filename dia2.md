# 🎯 Objetivo do Dia 2

O segundo dia do projeto teve como foco estruturar a solução definida anteriormente, organizando como o CabanaPay irá funcionar na prática. Nesta etapa, foram definidos os fluxos principais da aplicação, a jornada do usuário, os primeiros esboços das telas e a estrutura técnica inicial do sistema.

---

# 🧠 ETAPA 1 — DEFINIR COMO A SOLUÇÃO FUNCIONA

## ⚙️ Funcionamento Geral do CabanaPay

O CabanaPay será uma plataforma digital de pagamentos comunitários utilizando a blockchain Solana para garantir rapidez, baixo custo e transparência nas transações.

A aplicação permitirá:

* Pagamentos rápidos via QR Code;
* Transferências entre usuários;
* Sistema transparente de doações;
* Histórico completo de transações;
* Conexão com Phantom Wallet;
* Segurança financeira através da blockchain.

---

# 🔄 Fluxo Geral do Sistema

Usuário abre o aplicativo
↓
Conecta carteira Phantom
↓
Escolhe ação (pagar, receber ou doar)
↓
Sistema valida saldo
↓
Usuário confirma operação
↓
Transação enviada para Solana
↓
Confirmação instantânea
↓
Histórico atualizado

# 👤 ETAPA 2 — MAPEAR A JORNADA DO USUÁRIO

## 🎯 Jornada Principal do Usuário

### 📲 Entrada no Sistema

O usuário acessa o aplicativo pelo celular ou navegador.

### 🔗 Conexão da Carteira

A carteira Phantom é conectada para autenticação e movimentação financeira.

### 💸 Escolha da Função

O usuário poderá:

* Realizar pagamentos;
* Receber valores;
* Fazer doações;
* Consultar histórico.

### ✅ Confirmação

Antes da transação, o sistema exibe os dados para confirmação.

### 🚀 Finalização

A transação é registrada na blockchain e o usuário recebe a confirmação.

# 🚀 CONCLUSÃO DETALHADA — DIA 2

A etapa “Estruturando a Solução” foi essencial para transformar a ideia inicial do CabanaPay em uma estrutura funcional e organizada.

Durante esse processo, foi possível definir claramente como o sistema irá funcionar, quais serão as principais funcionalidades e como os usuários irão interagir com a plataforma.

O mapeamento da jornada do usuário ajudou a criar uma experiência mais simples, intuitiva e acessível, principalmente para pessoas com pouco contato com tecnologias financeiras.

Além disso, os fluxos de pagamento, recebimento e doações foram organizados de forma clara, permitindo compreender toda a lógica operacional da aplicação.

Os wireframes iniciais possibilitaram visualizar as primeiras telas do sistema, ajudando no planejamento da interface e experiência do usuário.

A definição da estrutura técnica também criou uma base sólida para o desenvolvimento do MVP, utilizando tecnologias modernas, seguras e escaláveis.

Com isso, o CabanaPay passa a possuir:

* Estrutura funcional organizada;
* Fluxos bem definidos;
* Arquitetura inicial planejada;
* Base visual estruturada;
* Direção clara para desenvolvimento futuro.

Essa etapa aproxima o projeto da construção real da aplicação, preparando o sistema para o desenvolvimento do front-end, integração com blockchain Solana e futuros testes com usuários reais da comunidade.
