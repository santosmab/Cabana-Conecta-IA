# 📍 VISÃO DO PROJETO

O CabanaPay será uma plataforma moderna de pagamentos comunitários criada para:
- Facilitar pagamentos rápidos;
- Permitir transferências acessíveis;
- Criar doações transparentes;
- Fortalecer o comércio local;
- Promover inclusão financeira;
- Utilizar blockchain Solana com baixo custo.

A aplicação deve parecer uma fintech moderna, simples e acessível para pessoas com pouco contato com tecnologia financeira.
