# 📍 SOBRE O PROJETO

O CabanaPay será uma plataforma de pagamentos comunitários criada para:
- Facilitar pagamentos rápidos;
- Permitir transferências acessíveis;
- Criar doações transparentes;
- Fortalecer pequenos comércios locais;
- Promover inclusão financeira;
- Utilizar blockchain Solana para segurança e baixo custo.

A plataforma deve possuir:
- Front-end moderno;
- UX intuitiva;
- Integração blockchain;
- Dashboard financeiro;
- Sistema de pagamentos via QR Code;
- Estrutura profissional para produção.
